# Tianyu Han — Bright Academic Website (with photo area)

This package is a complete static website.

## Design direction
- Bright and elegant color palette
- Conventional academic personal-site layout
- Hero image expresses the idea: our future is the stars and the sea
- Minimal and concise structure
- No unnecessary long-scroll sections
- Homepage includes a reserved place for your photo

## Photo
The homepage currently uses:
assets/profile-placeholder.svg

To replace it with your own photo:
1. upload your photo into the assets folder, e.g. assets/profile.jpg
2. open index.html
3. replace:
   assets/profile-placeholder.svg
   with
   assets/profile.jpg

## Upload
Upload everything in this folder to the repository root:
- index.html
- research.html
- publications.html
- styles.css
- favicon.svg
- assets/
- papers/

No framework or build step is required.
