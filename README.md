# Tianyu Han — Space-style Personal Academic Website

This package is a complete static website. You can replace the entire contents of a GitHub Pages repository with these files.

## Design direction

- SpaceX-inspired in feel:
  - full-screen hero
  - dark immersive presentation
  - minimal uppercase typography
  - strong visual hierarchy
- Adapted for a personal academic website:
  - homepage is about Tianyu Han as a person and researcher
  - research themes are broad
  - publications live on a separate page
  - no single technique defines the site identity

## Important note

The universe background is implemented as a full-screen animated HTML5 canvas rather than a giant GIF.
This gives a smoother and more premium effect while keeping the site lighter and more responsive.

## Upload structure

Upload all files in this folder to the repository root:

- index.html
- research.html
- publications.html
- 404.html
- styles.css
- script.js
- favicon.svg
- assets/
- papers/

No framework, no npm, no build step.
